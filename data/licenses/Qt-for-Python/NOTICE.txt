Qt for Python (PySide6, shiboken6) and Qt
=========================================

This bundle contains Qt for Python (the PySide6 and shiboken6 packages) and the Qt
libraries they load. They are distributed here under the GNU Lesser General Public
License, version 3 (LGPL-3.0.txt, which refers to the GNU General Public License,
version 3, in GPL-3.0.txt). The packages' own metadata states the licence as
"LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only"; this bundle uses the LGPL-3.0 option.

The Qt for Python and Qt libraries are separate files in this bundle, loaded
dynamically, so a modified build of them can be substituted for the ones shipped here.
Their source code is available from the Qt Project, https://code.qt.io, and from
https://www.qt.io.

This project's own licence is LICENSE.md at the top level of the bundle.
