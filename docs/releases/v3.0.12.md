# SWI3S Studio v3.0.12

A quality-gate release: one release gate, a lint-clean tree, a type ratchet, a leak scan and
content tiers. No user-facing behaviour changes and no ABI change (`score_abi` 8).

## Release gate

- **`tools/gate.py` is the gate**, with `tests/gate.sh` and `tests/gate.ps1` as thin wrappers.
  It rebuilds the native core and asserts its `score_abi`, then runs the suite, the
  performance gate, a per-suite pass, the linter, the type ratchet and the leak scan. It
  aggregates failures, and treats a missing tool as a failure.
- `tests/test_release_gate.py` fails if CI declares a check the gate does not run.

## Lint and types

- ruff is blocking and the tree is clean. Pure-layout rules are ignored in configuration.
- mypy runs as a per-file non-regression ratchet against a recorded baseline.
- The palette keys that `apply_palette()` sets on `VizTheme` are declared as class
  annotations, so the type checker sees them (no runtime change).

## Leak scan

- `tools/leak_scan.py` runs in the gate. It carries only structural patterns (private IP
  ranges, home paths, key file names, private-key headers), scans file names and printable
  runs inside binaries as well as content, reads site-specific names from a file outside the
  repository, and says so when that file is absent.

## Versions

- `swviz/version.py::APP_VERSION` matches `__version__`, the legacy-CSV conversion note uses
  the live version, and a test pins the version literals to each other.

## Documentation and publishing

- The CI documentation states where CI runs, with a table of what each gate does not cover.
  The CI matrix includes Windows with Python 3.14.
- Content is tiered by audience: a local-only tier (gitignored), a maintainers' tier, and the
  public tree. The prune is by path.
- `tools/publish_tree.py` builds the published tree and verifies it: the prune happened, no
  dangling references remain, the leak scan passes on the pruned tree, and the suite passes
  on it. The published tree is the release tree minus the maintainers' tier.
