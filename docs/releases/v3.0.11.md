# SWI3S Studio v3.0.11

SSPA (Stream Sync Point Announce) support end to end, expandable per-command statistics,
per-region bus geometry, a placement fix for partial channel groups, and build prerequisites
checked before building. Native ABI 7 → 8 (`DecoderSettings` gains `forced_column_sections`).

## SSPA

- All four demo captures emit a periodic SSPA (about every 100 ms) in every region with an
  active data port. The command is placed in the CDS so that the SSP its Row_Delay implies
  lands on a row aligned to every enabled port's interval (the LCM of Interval+1), and the
  audio-decode data ports are re-anchored there. A region too short for the period gets one
  SSPA at its midpoint.
- SSPAs can be filtered in the command table.
- **A partial capture locks its SSP backwards from an SSPA.** A capture that starts after the
  setup commit projects the SSPA's sync point back over the rows before it, so audio there
  decodes.
- An SSPA that arrives while a flow-controlled port is at its sync point keeps the port's DRQ
  pipeline, so the d = FlowControlDelay+1 handshake holds.

## Statistics

- A command row folds open: Ping per peripheral (PING_ALERT_BUSY, PING_ALERT,
  PING_ATTACHED_BUSY, PING_ATTACHED, NO_RESPONSE), and reads and writes per device (counts,
  error counts, bytes transferred).

## Decode

- **Bus geometry can be forced per region.** A config CSV's column count applies to the
  cursor's region, which the timeline labels "12col (forced)". A count forced by an earlier
  import is not reapplied to a later decode.
- **A partial channel group transports its real size.** Every interval carries exactly
  enabled_channels × (SampleGrouping+1) × (SampleSize+1) data slots; a trailing group smaller
  than ChannelGrouping counts down from its own size (native core).

## Bus Grid

- Click a data port's key to choose which fields its cells show, with a live preview on a
  real cell and an option to apply the choice to every data port.

## Demo captures

- Each demo answers Ping only for the devices it instantiates; undriven PingInfo slots carry
  the 0x3FF undriven symbol.
- A demo of the join-late workflow: the capture starts after the config commit, and the
  geometry comes from a CSV.

## Build

- The native build requires the Python development headers at configure time
  (`PYBIND11_FINDPYTHON` on, `Development.Module` required) and names the package to install
  when they are missing.
- Both launchers check for `Python.h` before creating a venv or downloading wheels; `run.sh`
  prefers an interpreter that has headers when several are on PATH. Either launcher stands
  aside when `SKBUILD_CMAKE_DEFINE` already points the build at headers elsewhere, and
  `native/build_local.sh` honours `PYTHON_INCLUDE`.
- The README documents the prerequisite, with recipes for hosts without root access.

## Tests

- The Visualizer reference model (`dataport.py`, `flow_control_port.py`) carries no comments,
  enforced by a test.
- The suite has no skips: tests that needed real captures run on the synthetic demo captures.
- The partial-channel-group fix is tested as an invariant over 85 parametrised cases.
- A collapsed command group in Statistics hides its error row too.
- "Apply to every data port" covers ports configured in every region.
- The timeline legend describes SSP Announce as the painter draws it.
