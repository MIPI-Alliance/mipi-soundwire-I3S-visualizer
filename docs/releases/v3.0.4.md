# SWI3S Studio v3.0.4

On-demand port-sample decode in Raw Capture, Row Sync Point cursors, a TX-map Bus Grid and
Apply Config CSV.

- Raw Capture decodes port samples on demand for the window shown, without a full re-decode.
- Commit and command cursors are placed at the Row Sync Point, including the grid geometry of
  a commit that changes the column count.
- The Bus Grid can draw a TX-map raster.
- A config CSV can be applied to a capture that is already open.
- Selection copy and hover details in the panes.
