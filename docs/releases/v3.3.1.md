# SWI3S Studio v3.3.1

Two tests pass on a machine without audio output support or with a wider default font. The
application is the same as in 3.3.0, whose changes are in `docs/releases/v3.3.0.md`.

## Testing

- **The new-audio-lane test checks the output device only where QtMultimedia imports.**
  Without QtMultimedia an Audio view lists no output devices, so a lane keeps device index 0;
  the bit depth it takes from the pane is checked everywhere.
- **The diagram title test finds the width its beside case needs from the font.** It widens
  the Timing page from 1800 px until the title fits on one line beside the column choice, and
  then checks that the title is placed there.
