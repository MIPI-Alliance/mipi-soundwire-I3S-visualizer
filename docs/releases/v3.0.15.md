# SWI3S Studio v3.0.15

The settings dialog's width is a floor, and the second-platform gate is a scripted step of
the release checklist. No product change beyond the dialog layout.

## Settings dialog

- The width is `max(470, sizeHint, title)`: 470 px is a floor, so a wider font widens the
  dialog instead of clipping its labels.
- `_ElidingLabel` reports its minimum for both `sizeHint` and `minimumSizeHint`, so a long
  summary does not resize the dialog.

## Release process

- Step 3 of the release checklist, before tagging, gates the exact commit on every configured
  platform with one command and returns one verdict, nonzero if any fails. A platform with
  nothing configured reports UNTESTED, which is not a pass.
- The leak scan ignores a `$`-prefixed `ssh -i` argument and still flags a literal key path.

## Tests

- The dialog-width test grows the font size until the widest label reaches 272 px, whatever
  font family the platform provides, and fails if it cannot.
