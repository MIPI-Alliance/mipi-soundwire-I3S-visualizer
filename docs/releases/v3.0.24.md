# SWI3S Studio v3.0.24

This release includes everything in 3.0.23, 3.0.22 and 3.0.21, described in
`docs/releases/v3.0.23.md`, `docs/releases/v3.0.22.md` and `docs/releases/v3.0.21.md`: Links
brought up again decode again (DLV included), a paused clock decodes on, maximize a pane, the
Registers filter by provenance, Audio drawn as its samples when zoomed in, the app quitting
with its window and on Ctrl+C, PySide6 6.12, and Python 3.11 kept running on Linux in every
process. It changes only how the performance checks judge a shared CI runner.

## Checks

- **A shared CI runner has its own ceilings for the two whole-window performance checks**:
  moving the cursor and switching Links with every pane open. On such a runner the Link switch
  has the ceilings Windows has, and the cursor move twice its usual ones. The ceilings
  everywhere else are unchanged.
