# SWI3S Studio v3.0.10

Large captures open safely, with a time window when the whole file will not fit; fixes to
audio gaps, channel-group spacing and quitting mid-load; and a test runner that runs every
test. Native ABI unchanged (`score_abi` 7).

## Large captures

- The memory an open needs is predicted from the `.sal` zip directory alone, without
  inflating anything, and a load that will not fit in 60% of available memory is refused
  before it allocates.
- The dialog then offers a **time window**: only that span is decoded, seeking the version 3
  block chain by its per-block headers and streaming the blob, so the cost scales with the
  window rather than the file. Reading a capture's length is cheap.
- The window is recorded in the session source, so a workspace reopens the same slice.
- A windowed decode is byte-identical to the same slice of a full decode.

## Fixes

- **The audio waveform breaks at gaps.** Two active regions separated by a stretch with no
  decoded samples are no longer joined by a line, and an envelope bin that straddles a gap is
  split.
- **Channel-group spacing stays within its row.** With Spacing ≥ 2 and a transport window
  that closes before the countdown ends, the remainder no longer carries into the next row.
  Fixed in both placement engines, the native decode core and the Visualizer's.
- **Quitting mid-load no longer aborts.** The capture-load, sub-capture-search and
  TX-persistence threads are all joined on close, by `MainWindow.join_worker_threads()` and an
  `atexit` hook.
- The demo synthesiser's idle CDS is the D10.2 0101 pattern rather than all ones, so an idle
  FBCSE bus toggles as a real one does.

## Window

- The demo captures are labelled by PHY throughout: PHY1 (FBCSE), PHY2 (FBCSE), PHY2 (Flow
  Control), PHY3 (DLV).
- The CDS symbol pane selects and copies per cell, as the Command table does: pick a cell or
  drag out a range and press ⌘/Ctrl+C.

## Tests

- `tests/run_all.sh` runs each suite through pytest, so it runs the same tests as CI, with
  per-suite reporting and process isolation.
- `tests/test_collection.py` fails if any test file collects no tests.
- A new `spacing_overflow` directed test covers a transport window that ends at the last
  column.
- The `__main__` blocks in test files are removed, except the authoring-golden `--regen`
  tool, which is documented.
