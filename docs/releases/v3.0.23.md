# SWI3S Studio v3.0.23

This release includes everything in 3.0.22 and 3.0.21, described in `docs/releases/v3.0.22.md`
and `docs/releases/v3.0.21.md`: Links brought up again decode again (DLV included), a paused
clock decodes on, maximize a pane, the Registers filter by provenance, Audio drawn as its
samples when zoomed in, the app quitting with its window and on Ctrl+C, PySide6 6.12, and
Python 3.11 kept running on Linux. It makes that last fix hold in every process.

Per-release detail is the changelog block at the top of `swi3s_studio/__init__.py`, newest
first; this file is the summary of the 3.0.23 entry.

## Platform

- **The Python 3.11 protection holds in every process.** PySide's Linux builds release
  references to `None` and `True` that they do not hold, and Python 3.11, where those objects
  are not immortal, aborts once a count runs out; the app pins them at startup. The pin
  judged its own write by an exact count, so a reference freed in between (by a garbage
  collection, for instance) made it undo itself, and that process ran unprotected. It now
  allows for other references meanwhile, runs with the collector off, pins any count it
  finds unpinned whenever it is called (the app calls it again once its window system is
  up), and warns on Python 3.11 when it cannot pin.

## Checks

- The leak scan, run on a tree that is not a git checkout, no longer reads the native core
  built beside it, which is never published and whose name carries the platform.
