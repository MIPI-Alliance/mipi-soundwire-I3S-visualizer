# SWI3S Studio v3.0.7

All three PHYs, each with a demo capture, and a development workflow with CI, linting, type
checks and a performance gate.

## PHYs and demo captures

- **File ▸ Load Demo Capture ▸ PHY1 / PHY2 / PHY3.**
- **PHY3 (DLV).** Differential-pair synthesis, and a decode front end with a virtual PLL that
  recovers the bit clock from the Sync1 row edges, samples mid-UI, reads a plain-NRZ CDS at
  Column 2 and feeds the shared FBCSE core; the PHY3 demo's audio is bit-identical to the PHY2
  demo's. At the commit the recovered clock speeds up 4x (Safe-Lock-4 to 16 columns) while the
  row rate stays at 3.072 MRows/s.
- Raw Capture shows the differential signal and the recovered bit clock, with a cycle count
  per row. The CDS symbol table, the Timing eye (setup and hold against the mid-UI sample
  point), the Statistics rates and the commit marker all follow DLV geometry and agree on the
  row where it changes.
- **PHY1 (FBCSE-slow) demo:** a constant 4-column bus whose ports are repositioned
  mid-capture by a placement-only commit.
- Every demo is sampled at 500 MHz (2 ns), a fixed analyzer rate rather than a multiple of the
  UI, so a UI spans a non-integer number of samples and the decode works from the actual
  edges.

## Cold-start bring-up

- The Bus Grid shows the bring-up sub-phase before PhyStart, then "PHYn Selected" once the bus
  is clocked.
- The grid viewport re-anchors on every re-render, so one click syncs it.
- The timeline's audio band is labelled "PHYn Safe-Lock-N", clear of the link-control bands.
- The Decoded Samples and CDS symbol panes no longer report their own programmatic selection
  as a user selection, which had desynchronised the cursor.

## Performance

- Demo edges are built with NumPy, and a demo loads on the background worker with a progress
  dialog, as an external capture does.
- `.sal` export deflates at level 1.
- Section UI statistics bisect the segment span.
- The Statistics pane is grouped into collapsible sections.
- The Decoded Samples pane fills without a repaint per item.
- macOS startup no longer warns "modalSession exited prematurely".

## Development

- A CI test matrix on Ubuntu, Windows and macOS, with golden fixtures.
- A performance-regression gate.
- ruff, mypy and coverage.
- Documentation of the development and release workflow, and a technical-debt register.
