# SWI3S Studio v3.0.14

CDS dialog widths fit their font, and the rich-text ink test checks the delegate. No other
behaviour changes.

## CDS dialogs

- A button group takes the widest size hint in the group (`_fit_uniform`): no button is
  narrower than its content, all are equal so the value column aligns, and the width does not
  depend on the selected value.
- The label column is sized from its own labels.

## Tests

- The rich-text ink test renders through `_RichTextDelegate._doc` and compares the anchored
  render with the plain one, rather than requiring a pixel equal to the text colour. It skips
  where no glyphs rasterise.
- Every CDS dialog is also tested at 13 pt.
