# SWI3S Studio v3.0.8

Large-capture performance and responsiveness, an Export Capture dialog, `.sal` export that
other tools accept, partial PHY3 captures, and PHY1 in the Timing Calculator.

## Large captures

- `.sal` version 3 transition-delta blobs are decoded in the native core (`score_abi` 6).
- Cold and Warm Start detection reads a bounded prefix of leading edges instead of the whole
  capture.
- The DLV complementary-pair check rejects on edge counts before copying any data.
- Audio channels are grouped and time-ordered in one sort.
- TX-map persistence counts data edges rather than every UI, and runs on a worker thread for
  large regions: the grid shows a placeholder until it is filled, and cached regions draw at
  once.
- The TX map and Persistence show "No PHY Selected" in a cold start's pre-audio region, as
  the config layout does.
- Audio resampling is a bounded polyphase decimator (low-pass FIR, then drop samples) instead
  of a whole-capture FFT.
- The native decode reserves its audio vector, DLV clock recovery walks a forward edge cursor,
  and `.bin`, CSV and WAV export and PDM decode avoid over-wide temporaries.
- All of the above is output-preserving: results are byte-identical, or within DSP tolerance,
  against the goldens.

## Responsiveness

- The heavy half of a cursor move (register replay, the CDS symbol and Decoded Samples
  tables, the Bus Grid) runs once, from a single-shot timer, at the cursor's resting place;
  the cursor line still moves at once.
- The Symbols and Registers panes fill in bulk.
- The Bus Grid's content cache uses a cheap key and simple text labels.
- The register map, commit markers, filtered commands and CDS symbol selection are cached and
  bisected on a cursor move.
- The command table's column fit and the timeline's commit markers are bounded.
- Statistics are built when the tab is first shown.

## Export

- **File ▸ Analyzer ▸ Export Capture…** is one dialog: the format (`.sal`, `.bin` or CSV), the
  signals and their names, the range (the whole capture, or a time, bus-row or UI window) and
  the output file. A range is written as a rebased sub-capture (`Capture.subcapture`). `.bin`
  and CSV can drop a signal; `.sal` keeps the pair.
- `.bin` is one version-0 blob per channel; CSV is a digital CSV with one row per transition.
  Both read back into the app (`ingest.raw_export`).
- `.sal` export writes version-3 blobs and a complete version-22 `meta.json`, carries the
  trigger-store member and the capture's sample rate, and chunks the transition stream into
  blocks with a matching block count. The file opens in the capture software and still
  round-trips through SWI3S Studio.

## Partial PHY3 captures

- A mid-stream DLV capture with no §5.1.2 cold start is detected and decoded. A digital CSV
  whose two channels are a complementary pair (data == NOT clock) goes through the
  recovered-clock path: the sample rate is taken from the timestamp quantum, the Safe-Lock
  column count is detected by which framing gives CRC-valid commands, and RSPs, the CDS symbol
  table and the recovered clock are produced with no PHY select on the wire
  (`analysis.dlv_detect`; `Session(dlv=...)`, `from_digital_csv(auto_dlv=...)`).
- The Bus Grid draws the full operational frame (Sync1 at Column 0, CDS at Column 2, Sync0 at
  the last column) with no NumColumns commit on the wire.
- A DP/DN probe swap is corrected: detection tries both polarities and keeps the one that gives
  CRC-valid commands.
- Detection runs for every source (`.sal`, `.bin`, CSV, a reopened workspace), so an exported
  partial PHY3 capture decodes like the original.
- Show Toggles flags the CDS at its real column (Column 2 for DLV) across the full operational
  width.
- The Visualizer and Export Visualizer CSV show the operational DLV frame (16 columns, PHY3).

## Timing Calculator

- **PHY1 as well as PHY2.** A PHY selector in the top bar switches the specification. Both PHYs
  share the setup/hold inequalities (§11.2, Tables 128–130, Figures 174–179); PHY1 takes its
  own values from Table 129 (Per_t_DD and Per_t_ZD 14–50 ns, Man_t_ZD 14–30 ns) and Table 126
  (F_CLK 6.6 MHz maximum, 6.4 MHz target).
- The Specification column is read-only and shows the spec's own min/max; only the Example
  column is editable. Switching PHY reseeds both. The PHY is saved in the workspace and in the
  saved settings.
- The top bar is on two rows, and the Analyzer's Timing hold plot has its grid.

## Import Visualizer CSV

- Importing onto a capture that reconfigures mid-stream warns first: one config is imposed
  from row 0 and can match only one region.
- A file that is not a config CSV is rejected with a message.
- The SSP nudge shortcuts are ⌘K and ⌘L (−1 / +1).

## Window

- Dock title bars are a themed widget with a flat close button on the left, and the tab bar
  behind tabbed docks is flat.
- The Analyzer File menu: Import Visualizer CSV is renamed; Export Capture and Locate
  Sub-Capture are grouped with Open; Save Bus Grid Image is under View Bus Grid.
- The Register pane has a Clear Compare button beside Clear Edits, and a wider device picker.

## Code structure

- The `.sal` version 3 codec is a public API with one block-chain emitter.
- Dispatch on the capture source type is in `Session.from_source`, beside the `from_*`
  factories, so a new format is a one-file change.
- The Bus Grid slot names are one `GridSlot` enum, pinned by a test to the native core's
  `SLOT_NAMES`.
- One `_redecode_preserving` helper re-decodes while keeping the window's state.
- A direct cross-engine placement test compares the native decode with the Visualizer's
  engine.
- Performance tests run on a large synthetic capture (`tests/test_perf.py`).
