# SWI3S Studio v3.0.16

A corrected DRQ clash verdict in the Bus Visualizer, a command filter that responds on its
first keystroke, a config CSV that cannot divide the decoder by zero, a Linux build of the
native core, and release-gate checks that execute the gate. Gated on every supported platform
with one command.

## Fixes

- **DRQ clash direction.** A DRQ is clash-checked in its own direction, the opposite of its
  parent port's (`Device._drq_direction()`): two devices driving one DRQ column is a bus clash,
  several devices sampling it is not. Pinned in `tests/test_drq_clash.py`.
- **NumColumns_REG is clamped** to the protocol's limits in `SwI3sConfig::columnCount()`, for
  the live decode and the audio engine; the raw register value stays readable.
- **The command filter's first keystroke is fast.** One DisplayRole formatter serves `data()`
  and `search_text()`, so the filter matches what the cell shows, and typing is debounced.
- **Locate Sub-Capture refuses a second run** while one is in progress, before the file dialog
  opens.
- **Threshold fractions.** The swing in every crossing term is derived from `V_OH_frac` and
  `V_OL_frac`, and every crossing call site passes it.

## Build

- `native/build_local.sh` uses `$CXX` if set, else clang++, else g++, and adds
  `-undefined dynamic_lookup` only on macOS.
- `tools/gate.py` exports `$PYTHON`, naming its own interpreter, to every child process; the
  build takes `EXT_SUFFIX`, the include path and pybind11's headers from it.
- When the native build fails, the skipped `score_abi` assert is listed under NOT RUN HERE.

## Tests

- `tests/test_release_gate.py` executes `tools/gate.py` and `tools/mypy_gate.py` with their
  slow parts stubbed and asserts the exit code for seeded outcomes.
- `test_publish_tiers`, walking a tree without git, skips the native-core build products
  `.gitignore` names, matched by name.
- A second test platform runs on Linux.
