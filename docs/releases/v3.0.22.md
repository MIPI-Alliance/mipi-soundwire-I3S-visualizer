# SWI3S Studio v3.0.22

This release includes everything in 3.0.21, described in `docs/releases/v3.0.21.md`: Links
brought up again decode again (DLV included), a paused clock decodes on, maximize a pane, the
Registers filter by provenance, Audio drawn as its samples when zoomed in, the app quitting
with its window and on Ctrl+C, and PySide6 6.12. It adds a fix that keeps Python 3.11 running
on Linux.

Per-release detail is the changelog block at the top of `swi3s_studio/__init__.py`, newest
first; this file is the summary of the 3.0.22 entry.

## Platform

- **Python 3.11 on Linux no longer aborts.** PySide's Linux builds release references they do
  not hold: one to `None` each time they hand back an empty value (an item or index read for a
  role it does not hold, an invalid index, an unset action's data), and one to `True` each
  time a signal defined in Python is emitted. Python 3.12 and later make those objects
  immortal, so nothing happens there; on 3.11 the interpreter aborted once either count ran
  out ("deallocating None"), which the Registers pane reaches within a session. The app and
  the test suite now pin `None`, `True` and `False` at startup on Python 3.11, which is what
  later Pythons do. Every PySide release from 6.9 to 6.12 behaves this way on Linux; macOS is
  not affected.

## Checks

- CI runs `actions/checkout` and `actions/setup-python` at the first majors that run on
  Node 24, so their jobs no longer warn that Node 20 is deprecated.
