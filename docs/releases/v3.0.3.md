# SWI3S Studio v3.0.3

Windows support, a CDS disparity column and ping-period statistics.

- Windows is supported: x64 wheels, an MSVC build of the native core, and the `run.ps1`
  launcher.
- The CDS symbol table has a disparity column.
- Statistics report the ping period.
- Opening a version 0 `.sal` uses less memory.
- The repository carries the files needed to publish it as an open-source project.
